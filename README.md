# **直播预告｜DeepSeek Harness+AIStata MCP公开课：一切皆插件，打造你的专属科研Agent**

> 当很多人还在直接调用现成 Agent 跑回归、生成代码时，前沿研究者已经开始掌控Agent底层调度逻辑。 DeepSeek Harness（简称DSH）——**MIT协议开源、「一切皆插件」的Agent运行底座**，区别于成品化Agent产品，它把模型适配器、工具调用、沙箱、任务循环、子智能体委派、日志审计全部拆成可替换插件，真正实现：`Model + Harness = Agent`。

本次，我们带来首场面向实证科研场景的 DeepSeekHarness专题公开课。不再停留在简单对话式代码生成，带你从架构底层理解、部署、安装、插件定制与使用，打通DSH + MCP协议 + Stata 生态，构建一套可溯源、可校验、可复现的自动化实证流水线。

> 一句话区分： 豆包工作、Workbuddy、TraeWork是**开箱即用的成品Agent应用层**；DeepSeek Harness是**构建Agent的开源底层框架**，你可以基于它组装属于自己的科研智能体。
